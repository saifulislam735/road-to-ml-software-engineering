For C++, the closest simple one-liner is:

```powershell

g++ test.cpp -o test.exe; .\test.exe

```

If you want it to stop when compilation fails, use:

```powershell

g++ test.cpp -o test.exe; if ($LASTEXITCODE -eq 0) { .\test.exe }

```
